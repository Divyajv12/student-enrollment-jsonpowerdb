
 Student Enrollment Form using JsonPowerDB

📌 Description
This micro project is a **Student Enrollment Form** developed using **HTML, JavaScript, and JsonPowerDB**.
The application stores student records in the `STUDENT-TABLE` relation of the `SCHOOL-DB` database.
It supports saving new student records and updating existing ones using the Roll Number as the primary key.



 🚀 Benefits of using JsonPowerDB
- Schema-free and easy to use
- Serverless database
- High performance with minimum development time
- Supports REST API calls
- Ideal for small and medium web applications



 🧩 Scope of Functionalities
- Insert new student records
- Fetch student data using primary key
- Update existing student records
- Reset form to initial state
- Client-side validation (no empty fields)



🧑‍🎓 Input Fields
- Roll No (Primary Key)
- Full Name
- Class
- Birth Date
- Address
- Enrollment Date
